# 📊 Dashboard Interativo de Vendas

Este projeto é um painel de visualização de dados (dashboard) interativo desenvolvido em Python. O objetivo principal é analisar dados de vendas, permitindo a extração rápida de indicadores de desempenho e a exploração visual das informações.

O aplicativo já está publicado e rodando na nuvem! 
👉 **[Clique aqui para acessar o Dashboard ao vivo](https://linguagensdeprogramacao-hmgwtbcafnaawfxzqvs5sy.streamlit.app/)**

## 🚀 Funcionalidades

O dashboard oferece as seguintes funcionalidades:
*   **Filtros Interativos:** Permite filtrar os dados apresentados selecionando uma ou múltiplas categorias de produtos através do menu lateral.
*   **Métricas de Destaque (KPIs):** Exibe a Receita Total (R$) e o Total de Pedidos atualizados dinamicamente com base nos filtros aplicados.
*   **Visualização Gráfica:** Gráfico de área demonstrando a evolução mensal da receita.
*   **Exploração de Dados:** Uma tabela interativa contendo todos os dados detalhados.
*   **Exportação:** Opção de download dos dados filtrados em formato `.csv` diretamente pelo aplicativo.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:
*   **Python:** Linguagem de programação base.
*   **[Pandas](https://pandas.pydata.org/):** Biblioteca para manipulação, limpeza e análise da base de dados (`.csv`).
*   **[Streamlit](https://streamlit.io/):** Framework utilizado para a criação da interface web interativa de forma ágil.
*   **Streamlit Community Cloud:** Plataforma de hospedagem gratuita (deploy) para aplicações Streamlit.
